# 23 - Drone Terminology Glossary

## Quick Reference — 20 Most Important Terms

| Term | Definition |
|------|------------|
| **LiPo** | Lithium Polymer battery; most common drone battery chemistry |
| **KV** | Motor velocity constant; RPM per volt under no load |
| **ESC** | Electronic Speed Controller; drives brushless motors |
| **FC** | Flight Controller; the "brain" that stabilizes the drone |
| **PWM** | Pulse Width Modulation; standard signal for ESC control |
| **DShot** | DigitalShot; digital ESC protocol (no calibration needed) |
| **PID** | Proportional-Integral-Derivative; closed-loop control algorithm |
| **ArduPilot** | Open-source autopilot firmware for autonomous vehicles |
| **SITL** | Software In The Loop; simulates drone firmware on a PC |
| **MAVLink** | Micro Air Vehicle Link; lightweight telemetry protocol |
| **Throttle** | Motor power input; controls altitude |
| **Yaw** | Rotation around the vertical axis (left/right turn) |
| **Pitch** | Rotation around the lateral axis (nose up/down) |
| **Roll** | Rotation around the longitudinal axis (left/right tilt) |
| **RTL** | Return To Launch; automatic return-to-home failsafe mode |
| **GPS** | Global Positioning System; provides position and heading |
| **Compass** | Magnetometer; measures Earth's magnetic field for heading |
| **ELRS** | ExpressLRS; open-source low-latency RC link |
| **SBUS** | Serial Bus; FrSky inverted serial RC protocol |
| **PDB** | Power Distribution Board; splits battery power to ESCs |

## Frame

| Term | Definition |
|------|------------|
| **Frame** | Structural chassis holding all components together |
| **Arm** | Structural member extending from center plate to motor mount |
| **Center Plate** | Main plate where FC, battery, and electronics mount |
| **Motor Mount** | End of arm where motor bolts attach |
| **Landing Gear** | Legs that protect the underside during landing |
| **Dead Cat** | Frame geometry with swept-back arms (wider front/rear spacing) |
| **Stretch X** | Frame with longer front-to-back than side-to-side arms |
| **True X** | Symmetric frame with equal arm spacing |
| **H-Frame** | Arms form an H shape; common in heavy-lift builds |
| **Carbon Fiber** | Lightweight, stiff composite material for frames |
| **Arm Thickness** | Measured in mm (3mm, 4mm, 5mm); thicker = stiffer but heavier |

## Motor

| Term | Definition |
|------|------------|
| **Brushless Motor** | Motor without brushes; uses ESC-driven coils for rotation |
| **Stator** | Stationary inner part of the motor with copper windings |
| **Rotor/Magnet** | Rotating outer bell with permanent magnets |
| **KV Rating** | RPM per volt at no load; higher KV = faster spin, less torque |
| **Stator Size** | Width × height in mm (e.g., 2806.5 = 28mm wide, 6.5mm tall) |
| **Torque** | Rotational force; higher torque motors handle larger props |
| **Pole Count** | Number of magnets; typically 12-14 poles on drone motors |
| **CW/CCW** | Clockwise / Counter-Clockwise rotation direction |
| **Motor Direction** | Determined by wire order connected to ESC phases |
| **Thrust** | Upward force generated by motor + propeller combination |
| **g/W** | Grams of thrust per watt; measure of motor efficiency |

## ESC (Electronic Speed Controller)

| Term | Definition |
|------|------------|
| **ESC** | Electronic Speed Controller; converts FC signal to motor commutation |
| **Firmware** | Software running on ESC (BLHeli_S, BLHeli_32, AM32, BlueJay) |
| **BLHeli_32** | 32-bit ESC firmware; supports telemetry, dynamic timing |
| **AM32** | Open-source 32-bit ESC firmware; alternative to BLHeli_32 |
| **BlueJay** | Open-source firmware for BLHeli_S ESCs; adds DShot |
| **Bidirectional DShot** | DShot with ESC-to-FC telemetry for RPM filtering |
| **Motor Timing** | Advance angle; affects efficiency and throttle response |
| **Startup Power** | Minimum power to start motor spinning; too low = desync |
| **Demag Compensation** | Protects against demagnetization at high timing |
| **OneShot** | Analog protocol 4-8× faster than PWM (not commonly used now) |
| **ESCs per Motor** | One ESC per motor; some boards have 4-in-1 integrated ESCs |

## Propeller

| Term | Definition |
|------|------------|
| **Propeller** | Rotating airfoil that generates thrust |
| **Diameter** | Total tip-to-tip measurement in inches (e.g., 5" = 127mm) |
| **Pitch** | Distance prop would move in one revolution; affects speed vs thrust |
| **Blade Count** | 2, 3, 4, or more blades; more blades = more thrust, less efficiency |
| **CW/CCW Prop** | Matched to motor rotation direction |
| **Bullnose** | Rounded tip shape; more surface area, higher thrust |
| **Triblade** | Three-blade propeller; good balance of grip and efficiency |
| **Bi-blade** | Two-blade propeller; higher efficiency, less grip |
| **Gemfan** | Popular propeller manufacturer |
| **HQProp** | Premium propeller manufacturer |
| **Prop Balancing** | Matching weight on each blade to reduce vibration |

## Battery (LiPo)

| Term | Definition |
|------|------------|
| **Cell** | Single LiPo cell; nominal 3.7V, full 4.2V, min 3.3V |
| **S Count** | Number of cells in series (e.g., 6S = 22.2V nominal) |
| **mAh** | Milliamp-hours; measure of battery capacity |
| **C-Rating** | Discharge rate multiplier (e.g., 30C = 30× capacity in amps) |
| **Wh** | Watt-hours; total energy (Voltage × mAh / 1000) |
| **Balance Lead** | Extra connector for individual cell voltage monitoring |
| **Balance Charger** | Charger that equalizes voltage across all cells |
| **Storage Voltage** | 3.85V per cell; voltage for long-term storage |
| **DoD** | Depth of Discharge; percentage of capacity used |
| **IR** | Internal Resistance; higher = more voltage sag under load |
| **Voltage Sag** | Drop in voltage under high current draw |
| **Swollen Battery** | Puffed/domed LiPo indicating damage; must be retired |
| **BMS** | Battery Management System; cell protection circuit |

## Flight Controller

| Term | Definition |
|------|------------|
| **Flight Controller (FC)** | Main computer running stabilization and navigation firmware |
| **IMU** | Inertial Measurement Unit; accelerometer + gyroscope |
| **Accelerometer** | Measures linear acceleration (tilt, gravity) |
| **Gyroscope** | Measures angular velocity (rotation rate) |
| **Barometer** | Measures atmospheric pressure for altitude estimation |
| **Altimeter** | Barometer-based altitude sensor |
| **OSD** | On-Screen Display; overlays flight data on FPV video |
| **Firmware** | Software running on FC (ArduPilot, PX4, Betaflight, iNav) |
| **ArduPilot** | Full-featured open-source autopilot for all vehicle types |
| **PX4** | Professional open-source flight stack |
| **Betaflight** | FPV-focused firmware optimized for racing/freestyle |
| **iNav** | Navigation-focused firmware for fixed-wing and GPS drones |
| **PID Tuning** | Adjusting control loop gains for stable flight characteristics |
| **Loop Rate** | FC processing frequency (e.g., 8kHz for Betaflight) |

## Navigation

| Term | Definition |
|------|------------|
| **GPS** | Global Positioning System; provides lat/lon/alt/velocity |
| **GNSS** | Global Navigation Satellite System; GPS + GLONASS + Galileo + BeiDou |
| **RTK** | Real-Time Kinematic; centimeter-level GPS accuracy |
| **NTRIP** | Networked Transport of RTCM via Internet Protocol; correction stream |
| **Waypoint** | Pre-programmed GPS coordinate for autonomous missions |
| **Mission** | Sequence of waypoints and actions for autonomous flight |
| **Loiter** | Hold current GPS position and altitude |
| **Guided Mode** | Accept position commands from ground station |
| **Navigate** | Follow waypoint mission autonomously |
| **Dead Reckoning** | Estimate position from last known position + velocity |
| **INS** | Inertial Navigation System; fuses IMU + GPS data |

## Communication

| Term | Definition |
|------|------------|
| **UART** | Universal Asynchronous Receiver/Transmitter; serial communication |
| **I2C** | Inter-Integrated Circuit; 2-wire bus for sensors |
| **SPI** | Serial Peripheral Interface; fast 4-wire bus for sensors |
| **CAN** | Controller Area Network; robust bus for industrial drones |
| **MAVLink** | Micro Air Vehicle Link; protocol for FC-to-ground communication |
| **Telemetry** | Real-time data stream from drone to ground station |
| **Ground Station** | Software running on PC/phone to monitor/control drone |
| **Mission Planner** | ArduPilot's ground station application |
| **QGroundControl** | PX4/ArduPilot cross-platform ground station |
| **OTA** | Over-The-Air; wireless firmware updates |
| **Bluetooth** | Short-range wireless for configuration (not for flight) |

## Safety

| Term | Definition |
|------|------------|
| **Failsafe** | Automatic action when RC link or other systems fail |
| **Geofence** | Virtual boundary that limits drone flight area |
| **Kill Switch** | Immediate motor shutoff for emergencies |
| **Arm/Disarm** | Enable/disable motor output |
| **Pre-arm Check** | System self-test before allowing motor arming |
| **Desync** | ESC loses synchronization with motor; causes sudden drop |
| **Brownout** | FC resets due to insufficient voltage |
| **Throttle failsafe** | Action taken when throttle signal is lost |
| **Link Quality (LQ)** | Percentage of successful RC packets received |
| **RSSI** | Received Signal Strength Indicator; RC signal strength |
| **Tether** | Physical restraint for testing; limits altitude and distance |
| **Prop Guard** | Physical barrier around propellers for indoor/safety flying |

## Regulatory

| Term | Definition |
|------|------------|
| **DGCA** | Directorate General of Civil Aviation; India's aviation authority |
| **UAS** | Unmanned Aircraft System; official term for drone |
| **RPAS** | Remotely Piloted Aircraft System; another official term |
| **Remote ID** | Broadcasting drone identity and location (required in many countries) |
| **Registration** | Official recording of drone with aviation authority |
| **Type Certificate** | Approval of drone design for commercial use |
| **Operations Certificate** | Permission to conduct commercial drone operations |
| **Green Zone** | Area where drones can fly without special permission |
| **Yellow Zone** | Restricted zone requiring ATC permission |
| **Red Zone** | No-fly zone; drone operations prohibited |
| **VLOS** | Visual Line of Sight; must see drone at all times |
| **BVLOS** | Beyond Visual Line of Sight; requires special authorization |
| **No-fly Zone** | Area where drone flight is prohibited (airports, military) |
| **Altitude Limit** | Maximum permitted altitude (typically 120m / 400ft AGL) |

## Testing

| Term | Definition |
|------|------------|
| **Thrust-to-Weight Ratio** | Total thrust / drone weight; must be >1.5:1 for good performance |
| **Hover Test** | First powered test hovering 1-2 meters off ground |
| **Ground Sweep** | Running motors with props at low throttle to check vibration |
| **Tethered Flight** | Flying while physically restrained by a rope/cable |
| **Maiden Flight** | First uncontrolled flight of a newly built drone |
| **Log Analysis** | Reviewing flight logs to diagnose issues |
| **Vibration Analysis** | Measuring motor/prop vibration frequency and amplitude |
| **Endurance Test** | Flying to measure maximum flight time |
| **Payload Test** | Testing with maximum intended payload weight |
| **Range Test** | Flying to maximum RC signal distance to verify link margin |
| **Bench Test** | Testing electronics on the bench without propellers |
| **Smoke Test** | First power-on to check for shorts or wiring errors |
| **Current Draw** | Measured amps at hover and full throttle |
| **Voltage Sag** | Battery voltage drop under load; indicates health |
