# 24 - Multirotor Physics: How Drones Fly

## Fundamental Principle

A multirotor flies by spinning propellers to generate **thrust** — an upward force that opposes gravity. By varying the speed of individual motors, the drone creates **torques** that cause rotation around three axes, giving full 6-DOF (degrees of freedom) control.

---

## The Four Forces of Flight

```
                    THRUST (T)
                       ↑
                       │
                       │
    DRONE ═════════════╪═════════════► Forward
                       │
                       │
                       ↓
                  WEIGHT (W = mg)
```

| Force | Source | Direction |
|-------|--------|-----------|
| **Thrust (T)** | Propeller + motor | Upward (opposite to prop wash) |
| **Weight (W)** | Gravity × mass | Downward (toward Earth center) |
| **Drag (D)** | Air resistance on frame | Opposing motion direction |
| **Lift (L)** | Generated by forward velocity (helicopter-like) | Perpendicular to velocity |

**Key relationship**: At hover, Thrust = Weight. For acceleration upward, Thrust > Weight.

---

## Hover Condition

For a multirotor to hover:

```
Total Thrust = Drone Weight

N × T_motor = m × g

Where:
  N       = number of motors (4 for quad, 6 for hexa)
  T_motor = thrust per motor (N)
  m       = total drone mass (kg)
  g       = gravitational acceleration (9.81 m/s²)
```

**Example for our 12S hexacopter:**
- Drone weight: ~12 kg (120N)
- Required total thrust: 120N
- Required thrust per motor: 120N / 6 = 20N
- Each motor needs to produce ~2 kg of thrust at hover

```

              ╲                    ╱
               ╲                  ╱
```

```
    M6 (CCW)    ╲──────────────╱    M3 (CW)
```

**Why alternating CW/CCW?** Adjacent motors spin opposite directions so their reaction torques cancel out in hover, preventing uncontrolled yaw rotation.

## How the Drone Moves

### 1. Hover (All Motors Equal Speed)

```
    M1: ████████████ 50%        M2: ████████████ 50%
              ╲                    ╱
               ╲                  ╱
                ╲     TOTAL      ╱
                 ╲  THRUST =    ╱
                  ╲  WEIGHT    ╱
                   ┌──────────┐
                   │  F = 0   │  ← Net force = 0
                   │  a = 0   │  ← No acceleration
                   └──────────┘
                  ╱            ╲
                 ╱              ╲
                ╱                ╲
              ╱                    ╲
    M3: ████████████ 50%        M4: ████████████ 50%

    Result: Drone hovers stationary
```

### 2. Throttle Up (All Motors Increase Speed)

```
    M1: ████████████████ 70%     M2: ████████████████ 70%
              ╲                    ╱
               ╲                  ╱
                ╲    THRUST >    ╱
                 ╲   WEIGHT     ╱
                  ╲             ╱
                   ┌──────────┐
                   │  F > 0   │  ← Net upward force
                   │  a > 0   │  ← Accelerating up
                   │    ↑↑↑   │
                   └──────────┘

    Result: Drone climbs
```

### 3. Yaw (Rotation Around Vertical Axis)

Yaw is controlled by **torque imbalance** between CW and CCW motors.

```
    ROTATE CW (clockwise yaw):

    M1: ████████████ 50%        M2: ████████████████ 60%
              ╲    slower          ╱    faster
               ╲                  ╱
                ╲                ╱
                 ╲              ╱
                  ╲            ╱
                   ┌──────────┐
                   │  CW Torque│  ← Net torque = CW
                   │   ↻      │
                   └──────────┘

    CW motors speed up → more reaction torque
    CCW motors slow down → less opposing torque
    Net effect: Drone rotates clockwise
```

**Physics**: Each motor produces a reaction torque on the frame opposite to its spin direction. CW motors create CCW torque on frame. By varying CW vs CCW motor speeds, we create a net torque.

```
    Torque = sum(CW motor torques) - sum(CCW motor torques)

    If net torque > 0: yaw CW
    If net torque < 0: yaw CCW
    If net torque = 0: no yaw (hover)
```

### 4. Pitch (Rotation Around Lateral Axis — Nose Down/Up)

Pitch is controlled by **front vs rear thrust differential**.

```
    PITCH FORWARD (nose down):

    M1: ████████████████ 65%     M2: ████████████████ 65%
    (front)                      (front)
              ╲    MORE           ╱    MORE
               ╲   THRUST       ╱   THRUST
                ╲              ╱
                 ╲            ╱
                  ╲          ╱
                   ┌────────┐
                   │        │
                   └────────┘
                  ╱          ╲
                 ╱            ╲
    M3: ████████████ 40%     M4: ████████████ 40%
    (rear)                       (rear)

    Front motors speed up → more thrust in front
    Rear motors slow down → less thrust in rear
    Net effect: Drone tilts forward, thrust vector angled
    Result: Drone accelerates forward
```

### 5. Roll (Rotation Around Longitudinal Axis — Left/Right)

Roll is controlled by **left vs right thrust differential**.

```
    ROLL RIGHT:

    M1: ████████████ 40%     M2: ████████████████ 65%
    (left)                      (right)
              ╲  LESS           ╱  MORE
               ╲               ╱
                ╲             ╱
                 ╲           ╱
                  ╲         ╱
                   ┌───────┐
                   │       │
                   └───────┘
                  ╱         ╲
                 ╱           ╲
    M3: ████████████ 40%     M4: ████████████████ 65%
    (left)                      (right)

    Right motors speed up → more thrust on right
    Left motors slow down → less thrust on left
    Net effect: Drone tilts right, thrust vector angled right
    Result: Drone accelerates right
```

## Why Multirotors Are Inherently Unstable

### 1. Center of Gravity vs Center of Thrust

```
    ┌─────────────────────────────┐
    │            CG               │
    │             ●               │
    │            /|\              │
    │           / | \             │
    │          /  |  \            │
    │         /   |   \           │
    │        /    |    \          │
    │       /     |     \         │
    │      /      |      \        │
    │     ●       ●       ●       │
    │   Motor    Motor    Motor   │
    └─────────────────────────────┘

    Thrust line passes THROUGH the CG only at exact center
    Any offset → torque → rotation → instability
```

### 2. No Passive Stability

Unlike fixed-wing aircraft (which naturally return to level flight), a multirotor has:
- **No dihedral** (no natural roll stability)
- **No sweepback** (no natural yaw stability)
- **No camber** (no natural pitch stability)

```
    Fixed wing:  Wind pushes wing up → dihedral → returns to level
                 UNSTABLE → stable (natural)

    Multirotor:  Wind pushes drone → no restoring force → tips further
                 UNSTABLE → UNSTABLE (needs active control)
```

### 3. Gyroscopic Precession

Spinning propellers create gyroscopic effects:
```
    If you push nose down → precession causes roll
    If you push right     → precession causes pitch

    The FC must account for this coupling in its control algorithm
```

### 4. Cross-Coupling

Movements in one axis affect others:
```
    Pitch forward     → slight altitude loss (thrust vector angled)
    Yaw rotation      → slight roll (asymmetric motor response)
    Roll right        → slight pitch change (drag asymmetry)
```

### The Control Problem

```

    ┌──────────────┐     ┌──────────────┐
    │   RC Input   │ ──► │  Manual mix  │ ──► Motors
    │  (4 channels)│     │  (fixed)     │

```

```
    WITH FC:
    ┌──────────┐    ┌────────────┐    ┌───────────┐    ┌─────────┐
    │ RC Input │───►│    PID     │───►│  Motor    │───►│ Motors  │
    └──────────┘    │  Controller│    │  Mixer    │    └─────────┘
                    └─────┬──────┘    └───────────┘
                          │
                    ┌─────▼──────┐
                    │   Sensor   │
                    │   Fusion   │
                    │ IMU+Baro+  │
                    │   GPS      │
                    └────────────┘
```

### What the FC Does (1000× per second)

1. **Read sensors** — gyroscope, accelerometer, barometer, GPS
2. **Fuse data** — Kalman filter combines noisy measurements
3. **Compute error** — difference between desired and actual state
4. **Apply PID** — calculate corrective motor commands
5. **Mix motors** — convert 4 axes (throttle, yaw, pitch, roll) to N motor commands
6. **Send to ESCs** — digital or analog signal to each ESC

### PID Control Loop

```
    Reference (desired) ──►┐
                           │    ┌───────────┐
                           ├───►│     P     │──┐
                           │    │ Kp × error│  │
                           │    └───────────┘  │
                           │    ┌───────────┐  │    ┌──────────┐    ┌──────┐
    Actual (measured) ────►│───►│  Sum      │──┼───►│  Output  │───►│Motor │
                           │    └───────────┘  │    └──────────┘    └──────┘
                           │                   │
                           │    ┌───────────┐  │
                           ├───►│     I     │──┤
                           │    │ Ki × ∫e dt│  │
                           │    └───────────┘  │
                           │    ┌───────────┐  │
                           └───►│     D     │──┘
                                │ Kd × de/dt│
                                └───────────┘

    P (Proportional): React to current error
    I (Integral):     Correct accumulated steady-state error
    D (Derivative):   Dampen rapid changes (prevent oscillation)
```

## Aerodynamic Principles

### Thrust Equation

```
    T = ρ × A × (V_exit² - V_inf²)

    Where:
      ρ     = air density (1.225 kg/m³ at sea level)
      A     = propeller disk area (π × r²)
      V_exit = velocity of air through propeller
      V_inf  = ambient air velocity (0 in hover)
```

### Power Required

```
    P = T × V_induced = T × √(T / (2 × ρ × A))

    Where V_induced = induced velocity at propeller disk
    
    Key insight: To double thrust, you need 2.8× the power!
    (Power scales with thrust^(3/2))
```

### Propeller Efficiency

```
    Efficiency (η) = Thrust × velocity / Power
    
    Best efficiency occurs at moderate throttle
    Efficiency decreases at very high throttle
    This is why larger props on lower KV motors are more efficient
```

## Stability Derivatives

The FC must account for these aerodynamic coupling effects:

```
    Pitch rate    → changes drag → changes pitch (pitch damping)
    Roll rate     → changes drag → changes roll (roll damping)
    Yaw rate      → gyroscopic coupling → changes pitch/roll
    Forward speed → changes lift distribution → changes pitch
    Side speed    → changes lift distribution → changes roll
```

## Common Physics Mistakes

| Mistake | Physical Consequence | Prevention |
|---|---|---|
| Insufficient TWR | Drone can't lift off or climb | TWR > 2.0 for safe operation |
| Ignoring arm length ratio | Uneven thrust distribution | Arms must be equal length, 60° apart |
| Wrong prop pitch for KV | Motor overloaded or underperforming | Match pitch to motor torque capability |
| Not accounting for battery sag | Reduced thrust under load | Use conservative hover estimates |
| Ignoring CG position | Unstable flight, drift | CG within 15mm of center |
| Ground effect at low altitude | Increased thrust near ground | Hover test at ≥1m height |
