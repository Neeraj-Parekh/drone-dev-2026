Core Physics Formulas

Reference mathematical models and physics equations used for performance calculations.

Core Physics Formulas

1. Dry Weight

DryWeight = Frame + (Motor×N) + (Battery×N) + Tank + GPS + PDB + Pump + FC + Wiring

Wiring = 500g (6AWG) + 100g (pads) + 50g (fuse) + 20g (BEC) + 50g (Rx) + 50g (sensor) + 200g (stopper) + 50g (strap) + 100g (misc)

2. MTOW

MTOW = DryWeight + (TankCapacity_L × 1000)

1L water = 1000g. Liquid payload assumed full tank.

3. Hover Thrust Per Motor

HoverThrust/Motor = MTOW / MotorCount

4. Hover Power

HoverPower/Motor = HoverThrust / Efficiency(g/W)

TotalHoverPower = HoverPower/Motor × MotorCount

5. Hover Current

HoverCurrent = TotalHoverPower / BatteryVoltage

6. Flight Time

FlightTime(min) = (UsableWh / TotalPower) × 60

UsableWh = Capacity_Ah × Voltage × DoD

TotalPower = HoverPower + PumpPower

7. Thrust Margin

ThrustMargin = (MaxThrust × MotorCount) / MTOW

Minimum 2.0x recommended for safety.

8. Battery DoD Estimation

Semi-solid @ 3C → DoD = 0.80

LiPo @ 25C+ → DoD = 0.75

Default → DoD = 0.80

Tweak Parameters

Default: 0.80. Lower = more conservative flight time estimate.

Default: 9.0 g/W. Higher = more efficient motor.

Default: 1120g. Includes wire, fuse, BEC, receiver, etc.

Default: 60W (Hobbywing pump). 0 if no pump.
