# RFD868x Telemetry Radio Specifications

**Source:** readymaderc.com, rfdesign.com.au

## General Specifications

| Parameter | Value |
|---|---|
| Frequency Range | 865–870 MHz (region-locked) |
| India Band | 865–867 MHz only |
| Tx Power | Up to 1W (+30 dBm), adjustable in 1dB steps |
| Air Data Rate | Up to 224 kbps (adjustable 12–750 kbps) |
| Rx Sensitivity | -111 dBm @ 12 kbps, -105 dBm @ 64 kbps |
| Range | 40+ km (line of sight with proper antenna) |

## Physical Specifications

| Parameter | Value |
|---|---|
| Weight | ~14.5g per unit |
| Dimensions | 30×57×12.8mm |
| Operating Temp | -40°C to +85°C |

## Features

| Feature | Details |
|---|---|
| Firmware | SiK on 32-bit ARM processor |
| MAVLink Support | Yes |
| Antenna Diversity | Yes |
| RC PPM Passthrough | Yes |
| AES-128 Encryption | Yes |
| Connectors | 2× RP-SMA RF, TTL serial (3.3V UART), 6× GPIO |
